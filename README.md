Each folder has the terms, an ECPP certificate (format of [CM](https://www.multiprecision.org/cm/), checked with `ecpp-check`) and an N−1
certificate for every term, the certificates as one zip, and a short check anyone can run.

Records for primes in arithmetic progression are kept by Norman Luhn at https://www.pzktupel.de/PAP/aprecords.php. The README in each folder gives the
record it was compared with and the date that list was read; this repository does not track later changes to it.
