# Primes in arithmetic progression: records by Arnav Garg

Arithmetic progressions of primes (AP-k: k primes p, p + D, ..., p + (k−1)·D) found by
[Arnav Garg](https://arnavgarg.in). Every term of every progression here is proven prime, with its certificates in
the record's folder.

Each folder has the terms, an ECPP certificate (format of [CM](https://www.multiprecision.org/cm/), checked with `ecpp-check`) and an N−1
certificate for every term, the certificates as one zip, and a short check anyone can run.

Records for primes in arithmetic progression are kept by Norman Luhn at https://www.pzktupel.de/PAP/aprecords.php. The standing column and the README in
each folder give the date the list was read; this repository does not track later changes to those lists.
